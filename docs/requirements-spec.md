# 需求规格说明书

## 项目名称：和基督徒同工一起面对宣教

## 1. 项目概述

### 1.1 项目背景
本项目旨在为基督徒群体打造一个宣教信息共享与协作平台。通过整合地图服务、宣教地信息、语言翻译工具及同工联系功能，帮助宣教参与者高效获取目标地区信息、分享经验、与当地同工建立联系，从而更好地预备和开展宣教工作。

### 1.2 目标用户
- 计划参与宣教的基督徒个人或团队
- 正在宣教地服务的宣教士
- 对宣教感兴趣、希望了解各地宣教情况的基督徒
- 在宣教地服事的本地同工

### 1.3 核心价值
- **信息聚合**：一站式获取宣教地综合信息
- **经验共享**：用户可分享亲历见证与实用注意事项
- **沟通桥梁**：建立与当地同工的直接联系渠道
- **语言支持**：提供翻译工具与文化背景知识，降低语言障碍

## 2. 功能需求

### 2.1 用户认证模块

#### 2.1.1 注册功能
| 项目 | 描述 |
|------|------|
| 功能描述 | 新用户通过填写注册信息创建账号 |
| 必填字段 | 用户名（唯一）、邮箱（唯一）、密码（8位以上，含大小写字母和数字） |
| 选填字段 | 所属教会、个人简介 |
| 验证规则 | 用户名2-20字符；邮箱格式校验；密码强度校验 |
| 异常处理 | 用户名/邮箱重复时提示已有账号，引导去登录 |

#### 2.1.2 登录功能
| 项目 | 描述 |
|------|------|
| 功能描述 | 已注册用户通过用户名/邮箱 + 密码登录系统 |
| 认证方式 | JWT Token 认证，Token 有效期7天 |
| 异常处理 | 账号或密码错误时提示"用户名或密码错误" |
| 附加功能 | 提供"记住我"选项，延长登录有效期至30天 |

#### 2.1.3 个人中心
| 项目 | 描述 |
|------|------|
| 功能描述 | 用户可查看和编辑个人信息 |
| 可编辑项 | 头像、所属教会、个人简介、联系方式 |
| 其他功能 | 查看自己的分享记录、私信记录 |

---

### 2.2 宣教地地图浏览模块

#### 2.2.1 地图展示
| 项目 | 描述 |
|------|------|
| 功能描述 | 进入系统首页即展示世界地图，地图上标注所有宣教地位置 |
| 地图标注 | 每个宣教地以标记点（Marker）展示，不同颜色区分不同区域 |
| 交互方式 | 点击标记点弹出信息卡片（名称、国家、简介摘要），点击卡片进入详情页 |
| 缩放与拖拽 | 支持鼠标滚轮缩放、拖拽平移 |
| 技术实现 | 使用 Leaflet 开源地图库 + OpenStreetMap 瓦片 |

#### 2.2.2 宣教地搜索
| 项目 | 描述 |
|------|------|
| 功能描述 | 用户可通过搜索框输入宣教地名称或国家进行搜索 |
| 搜索方式 | 支持模糊搜索，输入即搜，实时展示匹配结果下拉列表 |
| 搜索结果 | 点击搜索结果，地图自动定位到该宣教地，并弹出信息卡片 |
| 无结果处理 | 提示"未找到相关宣教地" |

### 2.3 宣教地详情模块

#### 2.3.1 宣教地简介
| 项目 | 描述 |
|------|------|
| 功能描述 | 展示宣教地的基本信息 |
| 内容 | 名称、所属国家/地区、人口、主要宗教、语言、简介文字、图片 |

#### 2.3.2 用户经历与见证
| 项目 | 描述 |
|------|------|
| 功能描述 | 注册用户可撰写和发布自己在该宣教地的经历与见证 |
| 发布内容 | 标题、正文（支持富文本）、图片上传 |
| 编辑功能 | 发布者可以编辑和删除自己的内容 |
| 展示方式 | 按时间倒序排列，支持分页加载 |
| 权限控制 | 未登录用户只能查看，不可编辑/发布 |

#### 2.3.3 注意事项
| 项目 | 描述 |
|------|------|
| 功能描述 | 用户可分享在宣教地的实用注意事项 |

| 编辑规则 | 每位用户可编辑自己发布的内容，管理员可管理所有内容 |

| 项目 | 描述 |
|------|------|
| 功能描述 | 展示该宣教地已注册为同工的当地联系人列表 |
| 联系渠道 | ① 系统私信（站内消息）② 邮件联系 |
| 权限控制 | 需登录后方可查看联系方式和发起联系 |

#### 2.4.1 日常用语翻译
| 项目 | 描述 |

| 项目 | 描述 |
|------|------|
| 功能描述 | 用户通过语音输入，系统识别后翻译并支持语音朗读 |

#### 2.4.4 文化背景与注意事项
| 项目 | 描述 |
|------|------|
| 功能描述 | 展示目标国家/地区的文化背景知识 |
| 内容 | 宗教信仰概况、社交礼仪、饮食习惯、节日习俗、禁忌事项 |

#### 2.4.5 大使馆/领事馆信息
| 项目 | 描述 |
|------|------|
| 功能描述 | 展示中国驻当地使领馆联系方式 |
| 内容 | 使馆名称、地址、电话、领事保护热线、办公时间 |

## 3. 非功能需求

### 3.1 性能要求
- 页面首屏加载时间不超过 3 秒
- 地图加载与交互流畅，无明显卡顿
- 翻译接口响应时间不超过 2 秒

### 3.2 安全要求
- 密码使用 bcrypt 加密存储
- JWT Token 安全传输
- 防止 XSS 和 CSRF 攻击
- API 接口鉴权，敏感操作需验证 Token

### 3.3 兼容性
- 支持主流现代浏览器（Chrome、Firefox、Safari、Edge 最新两个版本）
- 响应式设计，适配 PC 端和平板端

### 3.4 可维护性
- 前后端分离架构
- RESTful API 设计规范
- 代码结构清晰，模块化组织

## 5. 数据库设计
